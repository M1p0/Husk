# 可选兼容补丁

通用 Runtime 修复直接维护在 `src/` 中。应用或 SDK 的专用行为修改以独立 patch/mod 交付，由目标应用显式选择。默认 Runtime 不自动应用本目录内容。

| 类别 | 位置 | 引入条件 |
| --- | --- | --- |
| 通用修复 | `src/`，配套 `tests/` | 基于 ABI、ELF、指令或内存语义，具有独立验证 |
| 应用或 SDK 专用补丁 | 本目录下独立的补丁包 | 明确选择，且应用版本、库指纹及修改前置条件全部匹配 |
| 通用机制实验 | `experimental/` | 未完成的机制单独构建验证；明确契约并通过独立回归后再迁入核心 |

每个专用补丁包需要记录：

- 补丁 ID、用途、目标 Android 包名及版本范围。
- 目标库的 SHA-256 或同等强度的精确文件标识，以及修改前的预期字节或符号条件。
- 作用阶段、修改内容、平台限制、依赖和冲突。
- 显式启用方式、匹配失败时的处理及验证结果。

目标不匹配时拒绝应用。不能退化成仅凭库名套用固定偏移，也不能通过通用构建脚本批量引入全部补丁。专用补丁使用的公共机制可以进入核心，具体匹配规则和修改内容保留在补丁包中。

`apps/com.kurogame.mingchao/3.7.1/` 包含独立动态库形式的 SDK 线程探针、UE4 解密后代码补译、V8 与 Vulkan 兼容实验，按目标指纹匹配并逐项显式启用；已到启动/登录画面并播放声音，账号登录和游玩尚未验收。代码视图与安全点重翻译现为默认关闭的 macOS JIT 核心接口，游戏偏移、匹配和启用请求保留在模块中。安装器支持显式导入兼容包，按应用选择后端和补丁后自动保存，运行库统一跟随全局，见 `docs/14-macos-apk-installer.md`；模块通过固定版本的公开补丁 ABI 访问 Runtime；兼容的构建更新无需重新绑定游戏补丁。

当前分离针对本轮改动，不代表历史兼容代码已完成全仓库迁移。例如 loader 中原有的 `skip_boringssl_selfcheck` 是 SDK 行为修改，后续触及它时应按专用补丁迁移，不能当作通用指令翻译。
